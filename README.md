# EDGE-Infinity

**中文** · **English**

---

## 中文

这是一个面向成年人的**互动式边缘控制**网页体验：开场选择时长、难度与结局倾向后，由页面节奏与指令（可配合语音）引导整场过程。

你也可以通过 **「我有主人」** 导入自己的**本地资料包**（zip：文案 + 语音/图片文件夹），只在浏览器中解析，不上传服务器；不导入则使用网站默认内容。

内容明确偏向控制与服从主题，**仅供年满 18 岁且自愿的使用者**。请在安全、私密环境中体验。

公开地址：Cloudflare Pages（`edge-infinity.pages.dev`）。版本见仓库 `VERSION`。

---

## English

**EDGE-Infinity** is an **adult-only**, browser-based interactive session with timed guidance and rule-driven endings.

Via **“我有主人” (I have a Master)** you can load a **local content pack** (zip with scripts + audio/image folders). Parsing stays in the browser—nothing is uploaded. Without a pack, the site default content is used.

**18+ only.** Live site: `edge-infinity.pages.dev`. See `VERSION` for the release number.

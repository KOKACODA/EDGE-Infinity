## 中文

这是一个面向成年人的**互动式边缘控制**网页体验：你在开始前选定时长、难度与结局倾向，随后由页面节奏与指令（可配合语音）引导整场过程。绿色阶段可行动、红色阶段必须停下，最终是否被允许结束由规则与选项共同决定。

项目以静态页面形式托管，打开链接即可使用；内容明确偏向控制与服从主题，**仅供年满 18 岁且自愿的使用者**。请在安全、私密的环境中体验，并随时可以关闭页面中止。

当前公开访问地址见 Cloudflare Pages 部署域名（`edge-infinity.pages.dev`）。版本号以仓库内 `VERSION` 为准。

## English

**EDGE-Infinity** is an **adult-only**, browser-based interactive session built around timed guidance, restraint, and rule-driven outcomes. You choose length, intensity, and how the ending may resolve; the page then runs a sequence of on-screen instructions (optionally with voice), alternating permission to continue with mandatory pauses, until a final allow-or-deny resolution.

It ships as a static site—open the URL and play. Themes are explicit and control-oriented. **Only for consenting adults 18+.** Use it privately and stop whenever you need to.

The live deployment is on Cloudflare Pages (`edge-infinity.pages.dev`). See `VERSION` in the repository for the release number.

# EDGE-Infinity 结构说明

版本：`1.10.0`

---

## 本地资料包（zip）

网站「我有主人」支持导入/导出。

### 目录结构（勿改文件夹名）

```
EDGE-Pack/
  README.txt
  messages.json       ← 优先
  EDGE-内容.xlsx      ← 无 json 时可用
  audio/
    go/go_0.wav, go_1.wav, …
    stop/stop_0.wav, …
    finish/finish_0.wav, …
  images/
    go/ …
    stop/ …
    finish/ …
  video/
    go|stop|finish/   ← 预留，当前版本可不放
```

模板下载：`templates/EDGE-Pack.zip`

### 规则摘要

- 语音：`audio/{阶段}/{阶段}_{编号}.wav`，编号从 **0** 起，与文案 audioIdx 一致  
- 图片：放入 `images/{阶段}/`，导入后自动作为该阶段背景候选  
- 仅本机解析；刷新页面恢复网站默认  
- 也可只导入 `.xlsx`（语音仍用网站默认，除非 zip 内带 audio）

### Finish 颜色

- `green` = 允许释放  
- `red` = 不允许释放  
- 选项「不被允许排精」→ 只走 red 池  

### 开源库

- SheetJS CE：读/写 Excel  
- JSZip：解压/打包 zip  

### 其它

- 默认玩法：`messages.json` + 站点 `audio/`  
- 防搜索：`robots.txt` + `X-Robots-Tag` + meta noindex  
- 详细字段格式见历史说明；改逻辑主要动 `EDGE7/game.js`
